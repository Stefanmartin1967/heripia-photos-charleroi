# Photos de Heripia — Charleroi

Photos publiées de la destination **Charleroi** de [Heripia](https://heripia.com).

Ce dépôt ne contient que des photos : le code de l'app vit dans
[History-Walk-V1](https://github.com/Stefanmartin1967/History-Walk-V1). Chaque
destination peut avoir son propre dépôt de photos (champ `photosRepo` de
`destinations.json`), pour que chaque site GitHub Pages reste sous sa limite de
1 Go.

- Les fichiers sont écrits par l'app (« Tout publier » du Centre de Contrôle),
  dans `photos/`, un commit par photo.
- Chaque push sur `main` republie le site tel quel, sans construction
  (`.github/workflows/deploy.yml`).
- Adresse publique : `https://stefanmartin1967.github.io/heripia-photos-charleroi/photos/<fichier>.jpg`
